---
name: brainstorm
description: A back-and-forth to weigh the pros and cons of a raw idea before grilling it.
disable-model-invocation: true
---

Brainstorm the idea with the user in open dialogue. Give one point or counterpoint per turn. Let the user reply freely.

Name at least one alternative early. State your own verdict openly. Tally pros and cons only when the user asks.

Done when the user ends the discussion or you have stated a verdict the user has answered. Then write a short chat summary: the idea, the pros, the cons, the verdict.

- **Strong idea:** offer a grilling session. Call the `grilling` skill only after the user accepts.
- **Weak idea:** say so and name the main reason. Offer two options: drop the idea, or change it and restart.
